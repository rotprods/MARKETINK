# 3. CAPTURE MODES

Use only three visual modes.

## MODE A — FACE / FOUNDER

Use for:
- hook;
- business framing;
- transition;
- summary;
- important warning.

Frame:
- chest-up;
- eye line near upper third;
- clean, controlled background;
- one visual brand signal maximum.

## MODE B — SCREEN / IMPLEMENTATION

Use for:
- filling template;
- calculations;
- CRM/table examples;
- formulas;
- student action.

Requirements:
- 1440p minimum capture if practical;
- cursor visible;
- browser zoom sufficient;
- no private notifications;
- synthetic demo label visible.

## MODE C — GRAPHIC / MODEL

Use for:
- growth equation;
- funnel;
- capacity map;
- decision tree;
- recap.

Keep diagrams simple and reproducible.

---

# 4. AUDIO GATE

Audio quality outranks camera polish.

Minimum:
- external mic where available;
- stable gain;
- no clipping;
- room noise controlled;
- no music under critical calculations;
- consistent loudness across lessons.

Pilot QA:
- headphones;
- phone speaker;
- laptop speaker.

Fail if speech is tiring or unclear on any of the three.

# 7. EDITING SPEC

## Pacing

Remove:
- dead starts;
- cursor hunting;
- repeated phrases;
- setup friction;
- irrelevant UI waits.

Keep:
- decision pauses;
- difficult calculations;
- student checkpoint instructions.

## Captions

Required:
- Spanish;
- correct business terminology;
- manually QA numbers;
- no hallucinated auto-caption percentages.

## Zooms

Use only for:
- field being filled;
- key metric;
- menu path.

No constant push-ins.

## Callouts

Canonical callouts:
- `DO IT NOW`
- `QA`
- `WARNING`
- `UNKNOWN`
- `OUTPUT`
- `EXAMPLE`

## Music

Optional intro/outro only.
Never mask explanation.

# 10. PILOT QA MATRIX

Score 0–5 each:

| Dimension | Weight |
|---|---:|
| Business accuracy | 20 |
| Action clarity | 15 |
| Audio | 15 |
| Screen readability | 10 |
| Pacing | 10 |
| Template handoff | 10 |
| Visual consistency | 5 |
| Caption accuracy | 5 |
| Privacy/synthetic-data safety | 5 |
| Completion motivation | 5 |

Weighted pass:
**>= 90/100**

Hard fail:
- wrong calculation;
- unsupported claim;
- real private data visible;
- missing student action;
- audio clipping;
- resource link missing;
- synthetic example presented as client result.

# 11. REVIEW PROCESS

After first edit:

## PASS 1 — CONTENT
Watch at 1.5× with script.

Check:
- facts;
- numbers;
- sequence;
- terminology.

## PASS 2 — STUDENT
Watch as if following live.

Check:
- can I execute this without Roberto?
- do I know exactly when to pause?
- is the template enough?

## PASS 3 — MOBILE
Watch on phone.

Check:
- text;
- cursor;
- captions;
- chart labels.

## PASS 4 — AUDIO-ONLY
Listen without screen.

Check:
- explanation makes structural sense.

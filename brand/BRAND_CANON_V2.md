# 0. BRAND ESSENCE

MARKET.INK is the specialist growth system for tattoo studios and tattoo artists.

Visual territory:

```text
TATTOO CULTURE
× PREMIUM EDITORIAL
× OPERATOR PRECISION
× CONTROLLED RED SIGNAL
```

The visual system must feel artistic without becoming ornamental, technological without becoming generic SaaS, and premium without becoming sterile.

---

# 1. VALUES

Canonical values shown in the brand manual:

1. **Honestidad**
2. **Precisión**
3. **Libertad**

These should affect interface behavior:

- Honestidad → evidence-gated claims, visible methodology, no fake metrics.
- Precisión → exact spacing, restrained motion, structured systems.
- Libertad → expressive composition, artist individuality, non-template layouts.

# 4. LOGO SYSTEM

Observed canonical behaviors:

## Primary wordmark

`MARKET` in black + `INK` in red.

A brand-manual cover variant integrates a line-art rose between MARKET and INK.

## Monochrome

On light:
- black;
- black/red.

On dark:
- white;
- white/red.

## Isotypes

Two visual motifs appear consistently:
- red directional arrow / hand-like mark;
- line-art rose.

Use them as independent brand accents, not replacements for the wordmark unless context supports it.

---

# 5. LOGO SAFE USE

Manual specifies:

- minimum print width reference: **3 cm**;
- clear-space system uses a surrounding **X** unit;
- preserve aspect ratio;
- do not distort;
- do not split the wordmark;
- do not recolor INK arbitrarily;
- do not skew/italicize;
- do not combine separated fragments around unrelated images;
- do not stack letters into new compositions;
- do not use teal/green as replacement logo color.

Web implementation:
- reserve safe space around wordmark;
- minimum digital size should be QA-tested rather than inferred from print centimeters;
- logo remains selectable/readable where implemented as text fallback.

# 10. WEB DESIGN LOCK

The MARKET.INK web must preserve:

```text
LIGHT PAPER WORLD (#FBF8EF)
+ BLACK EDITORIAL TYPE
+ RED SIGNAL (#DE2727)
+ CONTROLLED DARK SCENES
+ ROSE / NEEDLE / INK / ARROW MOTIFS
+ HUGE TYPOGRAPHIC RHYTHM
+ PHYSICAL TATTOO TEXTURE
```

Forbidden defaults:
- purple gradients;
- generic cyan AI glow;
- glassmorphism everywhere;
- dark SaaS dashboard hero;
- fake cyberpunk tattoo visuals;
- neon signage cliché;
- gothic type just because the niche is tattoo.

# 11. CENTRAL WEB METAPHOR

**INK ENGINE**

The red arrow/isotype becomes a kinetic "signal core":

```text
ART
→ SIGNAL
→ CONVERSATION
→ BOOKING
→ REPEAT
```

The system may use:
- red extruded signal geometry;
- black ink droplet;
- rose/needle orbit language;
- booking/evidence panels;
- creative assets as satellites.

The metaphor represents MARKET.INK converting artistic work into measurable commercial motion.

3D must never replace the real tattoo work.

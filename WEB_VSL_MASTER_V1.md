# 6. V1 TECHNICAL ARCHITECTURE

## Framework

- Next.js 16.3.3;
- App Router;
- TypeScript;
- minimal dependencies;
- server-first components.

## Hosting

Vercel.

Why:
- first-class Next.js support;
- preview deployments;
- custom domains;
- later multi-project/multi-tenant path if MARKET.INK generates many client websites.

## Lead capture

Route:
`POST /api/inkscan`

V1 forwards sanitized lead payload to:
`MARKETINK_CRM_WEBHOOK_URL`

Secret:
`MARKETINK_CRM_WEBHOOK_SECRET`

No secrets in Git.

## Analytics

Start with:
- page view;
- VSL start;
- VSL completion where available;
- INKSCAN start;
- INKSCAN submit;
- booked call;
- qualified;
- won.

Do not stop at click analytics.

# 7. CLIENT WEBSITE FACTORY — LATER

For client websites:

### Early
Separate Vercel project per studio.

Advantages:
- isolation;
- simple ownership;
- custom domain;
- independent deploy.

### Scale
Evaluate Vercel for Platforms:
- Multi-Project if code/ownership differs;
- Multi-Tenant if a controlled common platform emerges.

Do not prematurely build a website builder.

# MARKET.INK

**Tattoo Growth OS — Academy + Done-For-You + Software Bridge**

MARKET.INK is a specialist growth company for tattoo studios and tattoo artists.

The operating thesis is:

```text
LEARN
→ IMPLEMENT
→ DONE-FOR-YOU
→ STANDARDIZE
→ AUTOMATE
→ INKFLOW
```
